# Tải AlienEvo cho Minecraft Bedrock 26.50

**[AlienEvo.mcaddon](AlienEvo.mcaddon)** — bản build 2.294.40

1. Xoá AlienEvo cũ trong **Cài đặt → Bộ nhớ** (cả Resource Pack và Behavior Pack).
2. Mở file `AlienEvo.mcaddon` để nhập vào Minecraft.
3. Bật cả **AlienEvo BP** và **AlienEvo RP** cho thế giới (nên tạo thế giới mới).
4. Mô tả gói phải ghi `(build 2.294.40)`.
